QURANIC DICTIONARY - 500 vocabulary entries

Host the complete folder over HTTPS to install as Android PWA. Open index.html on a web server; file:// does not support service workers.

Offline mode: after one successful online visit and service worker installation, bundled UI, vocabulary, quiz and progress can be used offline. Browser speech pronunciation may require internet or installed speech voices.

Notifications: reminders work while app/browser is running. Closed-app guaranteed reminders require native Android AlarmManager/WorkManager or server-side Web Push with subscriptions. Neither is included.

Vocabulary: first 126 entries are preserved from the supplied app; 374 entries are newly curated and require independent scholarly verification. Added entries intentionally have no fabricated frequency, verse citation, transliteration, or Roman Urdu.

Testing: JS parsing and database integrity checks passed. Browser integration testing was blocked by administrator network restrictions; real Android PWA installation is not verified.
