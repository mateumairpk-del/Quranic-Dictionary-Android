To update existing GitHub repository:
1. Open repository > Add file > Upload files.
2. Upload ALL contents of this folder (including .github) preserving directory structure. GitHub browser uploads may not support folder structure reliably; GitHub Desktop is easier.
3. Commit to main. GitHub Actions will rebuild automatically.
4. Download the new APK from Actions > latest successful run > Artifacts.
5. Install over old app (same package name).
